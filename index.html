Engineered for Craft & High Concurrency

Pure Python 3.8+ stdlib core designed for non-admin cross-platform workflows.

🔗

Non-Admin Junctions & Symlinks

Link skills across AI clients instantly with place --symlink using NTFS Directory Junctions on Windows (zero UAC admin elevation required) and POSIX symlinks on macOS/Linux.

⚡

Parallel Multi-Thread Engine

Concurrent skill uploads and downloads via --threads N powered by ThreadPoolExecutor. Sync dozens of skills in under 3 seconds.

🛡️

Proactive Credential Defense

Native pre-push scanner flags unintended OpenAI, Anthropic, AWS, or private keys before upload, supporting inline pragma opt-outs (# skill-sync: allow-secret).

☁️

Multi-Cloud Storage via Rclone

Sync seamlessly to Google Drive, Dropbox, OneDrive, S3, WebDAV, Nextcloud, or a local NAS directory with zero vendor lock-in.

🔄

Automated Session Hooks
