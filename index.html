¿Por qué SkillSync?

Diseñado para desarrolladores que buscan máxima velocidad, seguridad y cero fricción.

🔗

Junctions & Symlinks sin Admin

Con el flag place --symlink, vincula tus habilidades entre Claude Code, Gemini y Cursor al instante usando Directory Junctions en Windows (sin permisos de admin) y symlinks en macOS/Linux.

⚡

Sync Paralelo Multi-Hilo

Transfiere y sincroniza decenas de habilidades simultáneamente usando hilos concurrentes --threads. Reduce los tiempos de subida y descarga de 30s a menos de 3s.

🛡️

Escáner de Credenciales Nativo

Protege tu código evitando subir por accidente claves de API de OpenAI, Anthropic, tokens de AWS o contraseñas. Soporta exenciones por línea con `# skill-sync: allow-secret`.

📁

Multinube mediante Rclone

Compatible con cualquier proveedor de almacenamiento que soporte Rclone: Google Drive, Dropbox, OneDrive, S3, WebDAV, Nextcloud o una carpeta compartida en red local.

🔄

Hooks Automáticos de Sesión

Sincronización silenciosa en segundo plano al cerrar tu sesión de trabajo (Stop hook) y avisos automáticos al iniciar la jornada si hay actualizaciones en la nube.

🖥️

Interfaz TUI Interactiva

Incluye un menú visual interactivo en terminal (python scripts/menu.py) con casillas de selección, filtros en vivo y soporte ASCII/Unicode.

Compatible con todos tus Clientes de IA

Comandos Frecuentes

Control total desde la CLI de Python sin dependencias complejas.

python scripts/sync.py setup

Configura el almacenamiento remoto y las categorías por primera vez.

python scripts/sync.py push --threads 4

Sube habilidades modificadas a la nube en paralelo.

python scripts/sync.py pull

Descarga las habilidades disponibles desde la nube.

python scripts/sync.py place <skill> gemini --symlink

Crea un enlace simbólico instantáneo hacia otros clientes de IA.
