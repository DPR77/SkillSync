skill-sync
GTI Santander GitHub

Your AI skills,
on every machine you work from.

Install a skill once. Find it synced on the laptop, the desktop, and in whichever AI client you open next.

$ npx skills add DPR77/SkillSync

Multi-cloud sync

Works with Google Drive, Dropbox, OneDrive, S3, WebDAV, or a local folder via rclone. No lock-in.

Credential scanner

Pre-upload scan catches API keys before they leave your machine. Inline opt-outs supported.

Parallel transfers

Push or pull multiple skills at once with --threads N. Pure Python stdlib, no extra deps.

Session hooks

Auto-push at session close. One-line alert at session start if remote has updates.

Non-admin symlinks

NTFS junctions on Windows, POSIX symlinks on macOS/Linux. No elevated permissions needed.

Interactive TUI

Full terminal menu with arrow-key navigation, live search, and checkbox skill selection.

Claude Code Gemini Cursor OpenAI Codex Antigravity IDE
