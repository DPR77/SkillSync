Engineered for Performance & Trust

Zero-dependency Python core designed for seamless multi-environment workflows.

Non-Admin Junctions & Symlinks

Link skills across local clients instantly with place --symlink using Windows NTFS Directory Junctions (zero admin elevation required) and POSIX symlinks on macOS/Linux.

⚡

Parallel Multi-Thread Engine

Concurrent skill uploads and downloads via --threads powered by ThreadPoolExecutor. Sync 20+ skills in under 3 seconds.

🛡️

Proactive Credential Defense

Native pre-push scanner flags unintended OpenAI, Anthropic, AWS, or private keys before upload, supporting inline pragma opt-outs (# skill-sync: allow-secret).

☁️

Multi-Cloud Storage via Rclone

Sync seamlessly to Google Drive, Dropbox, OneDrive, S3, WebDAV, Nextcloud, or a local NAS directory with zero vendor lock-in.
